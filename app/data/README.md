| File | What it is | Generated by |
|---|---|---|
| `synonyms.json` | Synonym dictionary for Meilisearch and the API's expansion notice | hand-maintained |

## names_dict.csv

Stage 2 ingestion looks a speaker attribution up here after stripping honorifics and normalizing the name form (`ingest/canonical/names.py`). The lookup ignores case. A hit stores the canonical name with `speaker_name_unresolved = false`. A miss stores the attribution as written, with `speaker_name_unresolved = true`.

### Sources

| Corpus | Source | Licence |
|---|---|---|
| Lok Sabha, 1st–18th | Lok Sabha member directory on sansad.in (`https://sansad.in/api_ls/member?loksabha=N`), Lok Sabha Secretariat | Government of India publication. sansad.in publishes no open-data licence, and its robots.txt has no rules. Only member names are used: factual data, attributed here. |
| Rajya Sabha, sitting and former | Rajya Sabha member directory on sansad.in (`https://sansad.in/api_rs/member/sitting-members`), Rajya Sabha Secretariat | As above |
| Constituent Assembly | Wikidata: holders of position [Q61945113](https://www.wikidata.org/wiki/Q61945113) (member of the Constituent Assembly of India), English labels and aliases | CC0 1.0 |

The canonical name is the directory's own display name: first name and last name, without the honorific (e.g. `Hari Vishnu Kamath`). A Constituent Assembly member is linked to a Lok Sabha or Rajya Sabha entry in two cases:

- their Wikidata label or alias is the same name;
- they sat in the early Parliament and both names reduce to the same initials form (`G. V. Mavalankar`).

In either case, CA debates and later debates resolve to one name.

### Variants

For each member the generator writes:

- the full name;
- initials forms (`H. Vishnu Kamath`, `H. V. Kamath`, `H.V. Kamath`);
- the surname alone (`Kamath`);
- Wikidata aliases that share a word with the name;
- the same forms prefixed with any title that `strip_honorifics` keeps (`Acharya Kripalani`, `Sardar Hukam Singh`).

A key that maps to more than one person is left out. The exact full name of one member beats an initials form of another. The surname alone, or any one-word key, is kept only when no other member in any source has that surname. The dictionary has no dates, so it cannot tell Mahavir Tyagi (1950s) from K. C. Tyagi (2010s), and `Shri Tyagi` stays unresolved.

The generator does not produce spelling variants such as Choudhury / Chaudhury. A name the directory spells differently from the debates stays unresolved.

### Regenerating

Run from `app/`. The script is not part of the ingestion run. It makes about 23 requests, one per second.

```bash
python scripts/build_names_dict.py                          # fetch and rewrite data/names_dict.csv
python scripts/build_names_dict.py --save-members /tmp/m.json --report-ambiguous /tmp/ambiguous.json
python scripts/build_names_dict.py --members /tmp/m.json    # rebuild offline from a saved member list
```

Commit the new CSV. Already-ingested records keep their old names until Stage 2 is re-run (`docs/DEPLOYMENT.md` §6).
